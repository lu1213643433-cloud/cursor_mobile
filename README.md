# cursor_mobile

## Numbers 记账示例表

仓库中的 **`记账示例_导入Numbers.csv`** 可直接导入 Apple Numbers：

1. 在 GitHub 打开该文件 → **Raw** → 分享/保存到 iPhone **文件** App（建议放到 iCloud **快捷指令** 文件夹）。
2. 用 **Numbers** 打开 CSV，确认首行为表头：`日期`、`金额`、`类别`、`备注`。
3. 在 Numbers 中 **存储** 为 `.numbers`，供「快捷指令 → 添加到电子表格」选用。

也可删除示例数据行，只保留表头后长期使用。
